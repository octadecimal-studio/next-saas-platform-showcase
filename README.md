# Next SaaS Platform Showcase

Sanitized public mirror of a multilingual SaaS landing/application shell built
with Next.js, React and Tailwind.

## What This Demonstrates

- Next.js app router with localized routes
- React 19 and TypeScript UI components
- Tailwind/PostCSS styling
- next-intl navigation and messages
- Contact form validation with zod/react-hook-form
- SEO, sitemap, robots, OpenGraph and JSON-LD setup
- Playwright e2e and accessibility test structure

## Sanitization Notes

Deployment secrets and private operational docs were removed from history. The
repo is a portfolio showcase for frontend architecture and delivery workflow.
